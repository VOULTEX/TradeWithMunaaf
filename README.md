# Trade With Munaaf – Learning Community

A single-file static landing page (HTML + CSS + JS). No build step, no dependencies.

## Files
- `index.html` – the entire website (styles and scripts are inline)
- `profile.jpg` – **add your photo here with this exact name** (the hero avatar)

## Run locally
Just open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new repository (e.g. `munaaf-landing`).
2. Upload `index.html` and `profile.jpg` to the **main** branch root.
3. Go to **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Your site will be live at `https://<username>.github.io/<repo>/`
